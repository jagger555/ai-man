# 灵山胜境景区导览 AI 数字人｜启动脚本使用说明

## 这个压缩包包含什么

本压缩包仅包含：

- `start-local.bat`：Windows 双击启动脚本；
- 本说明文件。

它不是独立程序，不包含项目源码、数字人模型、形象素材或运行环境。

## 使用前必须完成的准备

1. 解压“主项目源码包”。解压后得到的项目根目录应包含 `backend`、`frontend`、`LiveTalking`、`scripts` 和 `README.md`。
2. 打开源码包中的 `README.md`，按“环境依赖与安装”完成 Python、Node.js、Conda 和 LiveTalking 环境配置。
3. 按源码包 README 提供的 Google Drive 链接下载数字人形象素材包，并将素材包解压到项目根目录。完成后应存在 `LiveTalking\data\avatars\708`。
4. 确认项目根目录中存在 `backend\.env`。该文件随完整源码包提供，已包含 API 配置。

## 如何使用启动脚本

启动脚本可以放在任意位置，不需要复制到源码包内。使用前先完成“准备”部分，然后任选一种方式启动：

### 方式一：双击后选择源码目录

1. 双击 `start-local.bat`。
2. 窗口提示 `Source project folder path:` 时，粘贴源码包解压后的**项目根目录**路径并回车。
3. 等待服务启动后，在浏览器打开 `http://127.0.0.1:5173`。

项目根目录是包含 `backend`、`frontend`、`LiveTalking`、`scripts` 和 `README.md` 的文件夹。

### 方式二：拖拽源码目录启动

将源码包解压后的项目根目录文件夹直接拖到 `start-local.bat` 文件图标上。脚本会自动识别该目录并启动。

### 方式三：脚本放在源码根目录

如果将 `start-local.bat` 放在项目根目录，直接双击即可，无需输入路径。

脚本不能在没有源码包的情况下独立运行；它会调用源码包内的 `scripts\start-local.ps1`。

## 常见提示

- 提示缺少 Python、npm 或 Conda：按源码包 README 安装对应环境后重试。
- 提示找不到数字人素材：确认已将素材包解压到项目根目录，而不是 `LiveTalking\data\avatars` 文件夹内部。
- 只需查看文字问答和管理后台时，可按源码包 README 使用 `-SkipLiveTalking` 启动。
